# خارطة التنفيذ حتى أول إصدار

كل مرحلة لها مخرج يمكن فحصه، وليس مجرد وصف «خلصنا».

| المرحلة | المخرج | الحالة الحالية | شرط إغلاقها |
|---|---|---|---|
| ٠: النطاق والقرارات | خطة وأدوار وقواعد وحدود ادعاء | منفذ | مراجعة متسقة مع المشكلة المحددة |
| ١: البيانات والأدوات | ٢٠ سيناريو، ١٠٠ نسخة، ٦ أدوات، مشغل وحكم | منفذ كتأسيس | صلاحية البيانات ونجاح اختبارات النواة |
| ٥: فحص الجودة والتكامل | تدقيق أنواع مستقل (TypeScript 5.8)، CI عبر GitHub Actions، ملف قفل | منفذ | كل بوابات الجودة تمر في بيئة نظيفة ومؤتمتة |
| ٢: واجهة محلية عربية | تطبيق React 19 + Vite 6 في `ui/`؛ اختيار حالة، تشغيل، سجل، مقارنة نسختين، تقرير | منفذ وتم التحقق منه | تجربة تفاعلية سريعة ولا تسرب للإجابة في سياق الوكيل |
| ٣: موصل نموذج واحد | استدعاء أدوات حقيقي على العالم الوهمي | مخطط للمرحلة التالية | مهلة وحدود كلفة ونداءات وتسجيل اسم وإصدار النموذج |
| ٤: مراجعة القياس | مراجعة بشرية ومجموعة غير مستخدمة في التطوير وتكرار تشغيل | مخطط | إعلان المنهج والنتائج والقيود دون مبالغة |
| ٦: نشر الإصدار النهائي | اسم ومستودع وREADME ورخصة وإصدار أول v0.1.0 | مستودع التأسيس منشور؛ الإصدار النهائي بعد الموصل ومراجعة القياس | تحديد الملفات والخصوصية وموافقة صريحة قبل النشر |
| ٧: ما بعد الإصدار | معالجة عيوب حقيقية وإضافة حالات لا مجرد مميزات | لاحق | إعادة الاختبارات وتحديث سجل التغييرات والدليل |

## ما تم إنجازه في الواجهة المحلية (ui/):
1. شاشة بداية ورأس صفحة بشارات الحالة والتحذيرات الصريحة (بيانات وهمية، محلي 100%).
2. مكتبة السيناريوهات العشرين مع بحث فوري وعرض تصنيف كل حالة.
3. شاشة الحسابات والملفات قبل التشغيل وبعده، مع تمييز الملفات المعدلة بالخطأ في الحساب غير المستهدف.
4. سجل نداءات تفاعلي (Trace) يميز محاولة الخطأ والأثر الفعلي المكتوب مع مدخلات واستجابات الأدوات.
5. زر مقارنة فورية بين النسخة الأصلية وعكس ترتيب الحسابات لكشف انحياز الموضع فورياً.
6. محاكاة شاملة (100 حالة × 3 وكلاء) مع إمكانية تصدير التقرير كـ JSON محلياً.

## تعريف انتهاء أول إصدار
واجهة قابلة للاستخدام، موصل واحد موثق، مرور اختبارات التشغيل والأنواع، مراجعة منهج القياس، دليل تشغيل وإزالة، رخصة صحيحة، وسجل نتائج يميز المرجع والضوابط والنماذج الحقيقية. النواة الموجودة وحدها لا تحقق هذا التعريف.

لا توجد مدة تنفيذ مضمونة أو تشغيل خلفي مستمر. بعد كل مرحلة منفذة يُنتج سجل حالة ودليل مالك محدثان؛ النسخ التي نزلها المستخدم لا تتحدث تلقائيًا.
