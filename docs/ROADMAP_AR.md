## ما تم إنجازه في الواجهة المحلية (ui/):
1. شاشة بداية ورأس صفحة بشارات الحالة والتحذيرات الصريحة (بيانات وهمية، محلي 100%).
2. مكتبة السيناريوهات العشرين مع بحث فوري وعرض تصنيف كل حالة.
3. شاشة الحسابات والملفات قبل التشغيل وبعده، مع تمييز الملفات المعدلة بالخطأ في الحساب غير المستهدف.
4. سجل نداءات تفاعلي (Trace) يميز محاولة الخطأ والأثر الفعلي المكتوب مع مدخلات واستجابات الأدوات.
5. زر مقارنة فورية بين النسخة الأصلية وعكس ترتيب الحسابات لكشف انحياز الموضع فورياً.
6. محاكاة شاملة (100 حالة × 3 وكلاء) مع إمكانية تصدير التقرير كـ JSON محلياً.

## تعريف انتهاء أول إصدار
واجهة قابلة للاستخدام، موصل واحد موثق، مرور اختبارات التشغيل والأنواع، مراجعة منهج القياس، دليل تشغيل وإزالة، رخصة صحيحة، وسجل نتائج يميز المرجع والضوابط والنماذج الحقيقية. النواة الموجودة وحدها لا تحقق هذا التعريف.

لا توجد مدة تنفيذ مضمونة أو تشغيل خلفي مستمر. بعد كل مرحلة منفذة يُنتج سجل حالة ودليل مالك محدثان؛ النسخ التي نزلها المستخدم لا تتحدث تلقائيًا.
