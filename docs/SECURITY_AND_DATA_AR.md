# السلامة والبيانات

- السيناريوهات مصطنعة، والأدوات لا تتصل بالإنترنت أو بخدمات حقيقية.
- تعديلات الأدوات على مصفوفات داخل الذاكرة، وليست عمليات نقل أو إعادة تسمية على القرص.
- سكربت التقرير فقط يكتب في `reports/` داخل مجلد المشروع.
- الوكيل يستلم دالة نداء الأدوات، وليس كائن العالم أو الإجابة المرجعية أو وسيلة تنفيذ أوامر.
- مع ذلك، موصل TypeScript محلي هو كود داخل عملية Node: هذا **ليس صندوق عزل لتشغيل كود مجهول**. لا تشغل موصلات غير موثوقة. أي دعم لتشغيل برامج خارجية يحتاج فصل عمليات وعزلًا فعليًا.
- لا تضع مفاتيح خدمات في الحالات أو التقارير. ربط نموذج حقيقي لاحقًا يرسل رسائل وبيانات وهمية لمزوده؛ يجب توضيح ذلك وعدم إرسال ملفات المستخدم الخاصة.
- قبل ربط نموذج: مهلة اتصال، سقف نداءات وتوكنات وكلفة قابلة للإعداد، تنقيح أسرار، ومعالجة انقطاع الاتصال وعدم اليقين في النتيجة.
- هذه أداة كشف سلوك محدد، لا شهادة امتثال أو ضمان منع كل تسرب أو حقن تعليمات.
- نشر مجموعة اختبار عامة يسمح بالاطلاع على أهدافها. فصل `oracle` وقت التشغيل لا يجعل ملفاته العامة سرية أو يمنع حفظها في تدريب نموذج.
- دليل المالك الشخصي منفصل عن أرشيف الكود؛ راجع قائمة الأرشيف يدويًا قبل نشر أي نسخة.
