# إضافة مساهمة مفيدة في المشروع

متطلبات البيئة: `Node.js >= 20.0.0`.

١. افتح `data/scenarios.json` وافهم بنية الرسائل، بيانات العالم المصطنع، والإجابة المرجعية.
٢. أضف سيناريو مصطنعاً لا يعرّض بيانات حقيقية لأحد، بمعرف فريد منضبط.
٣. تأكد أن التوجيه يحدد الحساب المستهدف بوضوح، أو أن الحالة غامضة وتتطلب استيضاحاً إلزامياً (`require_clarification: true`).
٤. حافظ على معنى الطلب عند تطبيق التنويعات (عكس ترتيب الحسابات، تبديل الافتراضي، أو إضافة حساب مضلل).
٥. شغّل حزمة الفحوصات الشاملة للتأكد من سلامة الأنواع والاختبارات الـ 63:
   ```bash
   npm test
   npm run check-all
   ```
٦. إذا أضفت أو عدلت ملفات في المستودع، قم بتحديث بيان البصمات والتحقق منه:
   ```bash
   npm run manifest:update
   npm run manifest:verify
   ```
٧. إذا تم تحديث أرقام التقييم أو السيناريوهات، شغّل سكربت المزامنة:
   ```bash
   npm run sync:reports
   ```
٨. أضف اختباراً مؤتمتاً يثبت أن السلوك الصحيح لا يعاقَب وأن الخطأ المقصود ينكشف بدقة.

لا تستخدم بيانات تشغيل حقيقية بدل البيانات المصطنعة بلا موافقة وتنقيح. لا ترفع نتائج مرجع الإجابة باعتبارها أداء نموذج حقيقي. تعديل قواعد الحكم قد يغيّر معنى كل رقم؛ أعطِه إصدارًا ودوّن السبب بدقة.
