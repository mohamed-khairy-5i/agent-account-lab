# إضافة مساهمة مفيدة

١. افتح `data/scenarios.json` وافهم الرسائل والعالم والإجابة المرجعية.
٢. أضف حالة مصطنعة لا تعرّض بيانات أحد، بمعرف فريد.
٣. تأكد أن المستخدم يحدد الحساب، أو أن الحالة تطلب سؤالًا بوضوح.
٤. حافظ على معنى الطلب عند تغيير ترتيب الحسابات أو الافتراضي.
٥. شغّل `node scripts/validate.ts` ثم الاختبارات ثم العرض.
٦. أضف اختبارًا يثبت أن السلوك الصحيح لا يعاقَب وأن الخطأ المقصود ينكشف.
٧. حدث عدد الحالات والتوثيق عند تغيير المجموعة، ولا ترفع دليل المالك أو الأسرار.

لا تستخدم بيانات تشغيل حقيقية بدل البيانات المصطنعة بلا موافقة وتنقيح. لا ترفع نتائج مرجع الإجابة باعتبارها أداء نموذج. تعديل قواعد الحكم قد يغيّر معنى كل رقم؛ أعطِه إصدارًا ودوّن السبب.
